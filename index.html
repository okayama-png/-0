PROLOGUE
000 - Prologue
きっかけはあの日入ったバー。あの時私がそのまま帰っていたら、みなみさんが別の予定のままだったら……そう思うと本当に奇跡や運命ってあるんだと感じます。見えなくなるまで改札で手を振り続けてくれた姿は、今も脳裏に焼き付いています。 会話が驚くほど楽しくて「この人のためなら」と思えたこと。公務員として働きつつ大好きなダンスを楽しむ真っ直ぐさや、緊張する私を「楽しい」と優しく包み込んでくれる笑顔に惹かれていきました。両思いだと分かっていても、「好きです。付き合ってください」と手を震わせて告白したあの夜の緊張は、大切な宝物です。 どの思い出も一つだって忘れたくないから。普段上手く伝えられない「大好き」を込めて、このアルバムを作りました。喜んでくれるといいな。 これからもたくさん思い出増やしていこう。その度更新するから、時々は見に来てね。

MEMORY 01
001 - 付き合った日
2026.07.03 みなみさんの仕事終わりに職場までお迎えに行って、近くでもんじゃ焼きを食べた日。昔バイトしてたみたいで、張り切って焼いてくれたのがめちゃくちゃ可愛かったな。 そのあとカラオケに行って、まだ付き合ってもないのにキスしちゃって……もう心臓バクバクで破裂するかと思った（笑）。 みなみさんの最寄り駅に着いてからは、公園までゆっくりお散歩。 実は私、告白するために花束と手紙をこっそり用意してて。そしたらみなみさんも、私の誕生日プレゼントにマグカップ用意してくれてたんだよね。 公園で花束を取り出して、緊張で声を震わせながら告白。無事にお付き合いスタート！ 最初は隣を歩くだけで照れくさいのに、みなみさんが無意識にぐいぐい寄ってくるから私の歩く道なくなっちゃうのも愛おしかった（笑）。 公園でずっとキスしてたのも今じゃ最高の思い出。すごくコーヒーの味がしたのを覚えてる。 ふたりの距離がぐんと縮まった、人生でいっちばん最高の夜！

003 - 七夕
2026.07.07 お互いに短冊を書き合って送り合った七夕の夜。 「ずっと隣で笑い合える関係でいられますように」って願いを込めて書いたんだけど、みなみさんの書いた字が美しすぎて……またさらに惚れ直してしまったな。しかも「大好き」なんて言葉まで短冊に書いてくれて、たまらなく幸せだった！ 笑顔でいられることが一番大切だと思うけれど、みなみさんとならどんな壁があっても乗り越えていける気がした。 これからも一生をかけて、みなみさんのことをもっと知っていきたいなと願った特別な夜でした。

MEMORY 05
005 - 水族館と初お泊り
